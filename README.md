 Todo CLI App 

A command-line task manager
built with Python.

 What it does:
- Add tasks
- Remove tasks  
- List all tasks
- Tasks saved permanently
  in JSON file

 Tech Stack:
- Python
- JSON file handling
- Error handling
- Functions

 How to run:
python todo_cli_app.py
